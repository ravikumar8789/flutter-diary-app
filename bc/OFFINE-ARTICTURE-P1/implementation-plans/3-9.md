# Phase 3.9: SyncWorker Processes All Entity Types

**Goal:** SyncWorker processes entries, streak, user_profile, and user_settings in a unified flow. Single entry point (`processSyncQueue`) handles all entity types when online.

**Prerequisites:** Phase 1.1, 1.2, 1.3, 2.4–2.6, 3.7 (sync queue schema + add to queue), 3.8 (no direct Supabase).

---

## 1. Entity Types and Processing

| entity_type | Source | Supabase Method | Mark Synced |
|-------------|--------|-----------------|-------------|
| entry | getUnsyncedEntries() | batchSaveEntry | entries + entry_* tables |
| streak | sync_queue (entity_type='streak') | batchUpdateStreakData | streaks, habits_daily |
| user_profile | sync_queue (entity_type='user_profile') | users.upsert | users |
| user_settings | sync_queue (entity_type='user_settings') | user_settings.upsert | user_settings |

---

## 2. processSyncQueue Flow (Target)

```
processSyncQueue()
    ↓
if (!_isOnline()) return
    ↓
1. Process entries (getUnsyncedEntries)
   - For each: load full entry + related from local → batchSaveEntry → markAsSynced
    ↓
2. Process sync_queue (entity_type IN ('streak', 'user_profile', 'user_settings'))
   - For each item: dispatch by entity_type → Supabase sync → remove from queue, mark local synced
    ↓
done
```

**Order:** Entries first (may trigger streak recalc), then streak, then user_profile/user_settings (parallel OK).

Future<List<SyncQueueItem>> getSyncQueueByEntityTypes(List<String> entityTypes) async {

  final results = await db.query(

### Step 3.4: Refactor processSyncQueue — Unified Processing

**File:** `lib/services/sync/sync_worker.dart`

**3.4.1** Replace current logic with:

```dart
Future<void> processSyncQueue() async {
  if (_isProcessing) return;
  _isProcessing = true;
  try {
    if (!await _isOnline()) return;

    // 1. Process unsynced entries (use batchSaveEntry with full data)
    final unsyncedEntries = await _localService.getUnsyncedEntries();
    for (final entry in unsyncedEntries) {
      try {
        final full = await _localService.getFullEntryForSync(entry.id);
        if (full == null) continue;
        final success = await _syncService.batchSaveEntry(
          entry: full.entry,
          affirmations: full.affirmations,
          priorities: full.priorities,
          meals: full.meals,
          gratitude: full.gratitude,
          selfCare: full.selfCare,
          showerBath: full.showerBath,
          tomorrowNotes: full.tomorrowNotes,
        );
        if (success) await _localService.markAsSynced(entry.id);
      } catch (e) { /* log */ }
    }

    // 2. Process sync_queue for streak, user_profile, user_settings
    final queueItems = await _localService.getSyncQueueByEntityTypes(['streak', 'user_profile', 'user_settings']);
    for (final item in queueItems) {
      try {
        final entityType = item.entityType;  // or item.data['entity_type']
        final entityId = item.entityId;      // user_id for these types
        bool success = false;
        if (entityType == 'streak') {
          success = await _syncService.batchUpdateStreakData(userId: entityId, streakData: item.data, habitsData: null);
        } else if (entityType == 'user_profile') {
          success = await _syncService.syncUserProfile(entityId, item.data);
        } else if (entityType == 'user_settings') {
          success = await _syncService.syncUserSettings(entityId, item.data);
        }
        if (success) {
          await _localService.removeSyncQueueItem(item.id);
        } else {
          await _localService.incrementRetryCount(item.id);
        }
      } catch (e) { /* log */ await _localService.incrementRetryCount(item.id); }
    }
  } finally {
    _isProcessing = false;
  }
}
```

**3.4.2** Update `hasUnsyncedEntries` check: also consider sync_queue. Run processSyncQueue if either unsynced entries OR sync_queue items exist.

### Step 3.5: Add hasSyncQueueItems Helper

**File:** `lib/services/database/local_entry_service.dart`

```dart
Future<bool> hasSyncQueueItems(List<String> entityTypes) async {
  final db = await _dbManager.database;
  final placeholders = entityTypes.map((_) => '?').join(',');
  final r = await db.rawQuery(
    'SELECT COUNT(*) as c FROM sync_queue WHERE entity_type IN ($placeholders) AND (retry_count IS NULL OR retry_count < 10)',
    entityTypes,
  );
  return (r.first['c'] as int) > 0;
}
```

## 5. Processing Order Rationale

| Order | Reason |
|-------|--------|
| Entries first | Entry save may trigger streak recalc; streak items added to queue after. |
| Streak second | Depends on entries/habits. |
| User profile, settings last | Independent; can run in parallel. |

---

## 6. Error Handling

| Case | Action |
|------|--------|
| batchSaveEntry fails | Don't mark synced. Retry on next processSyncQueue. |
| batchUpdateStreakData fails | incrementRetryCount. Remove if retry_count >= 10. |
| syncUserProfile fails | Same. |
| syncUserSettings fails | Same. |
| Duplicate key (users) | Catch, fetch from Supabase, update local, remove from queue. |
