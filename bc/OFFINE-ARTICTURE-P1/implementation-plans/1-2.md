# Phase 1.2: Remove DataRepository + Cache Layer

**Goal:** Remove in-memory cache. DataFetchService reads directly from Supabase/SQLite. No behavior change to data sources — only remove the caching wrapper.

**Prerequisite:** Phase 1.1 complete (users, user_settings tables exist — optional, not blocking).

---

## 1. Overview

| Before | After |
|--------|-------|
| Request → DataRepository.fetch() → cache check → fetcher() | Request → fetcher() directly |
| Invalidate calls scattered across app | No invalidate — use `ref.invalidate(provider)` only |
| DataRepository, CachedData classes | Deleted |

## 5. DataFetchService Methods — Unwrap Pattern

For each method, transform:
```dart
return await _repository.fetch<T>(key: key, fetcher: () async {
  try {
    // actual logic
    return result;
  } catch (e) { ... rethrow; }
});
```
To:
```dart
try {
  // actual logic (same as fetcher body)
  return result;
} catch (e) { ... rethrow; }
```
