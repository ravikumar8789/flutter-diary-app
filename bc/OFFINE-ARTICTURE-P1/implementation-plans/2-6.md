# Phase 2.6: Remove Destructive last_sync_at = null

**Goal:** Remove all code that sets `last_sync_at = null` to force a fresh fetch. This is destructive because it wipes sync state and causes every startup to overwrite local with Supabase, ignoring the "merge by timestamp" rule.

**Rule:** Only overwrite local when `Supabase.updated_at > local.last_sync_at` (or local empty). Never invalidate `last_sync_at` to force overwrite.

**Prerequisites:** Phase 1.1, 1.2, 1.3. Can run before or after 2-4 (if 2-4 removes `calculateStreakOnAppLaunch`, 2-6 verifies no remaining destructive code).

### Step 2.2: Replace Overwrite Logic with Timestamp Comparison

**File:** `lib/services/user_data_service.dart`

**Current logic (line 947):**
```dart
if (localStreak.isEmpty || localStreak.first['last_sync_at'] == null) {
  // Always overwrite with Supabase
```

**New logic:** Only overwrite when Supabase is newer or local is empty.

```dart
final localLastSyncAt = localStreak.isNotEmpty
    ? (localStreak.first['last_sync_at'] as String?)
    : null;
final supabaseUpdatedAt = supabaseStreak['updated_at'] as String?;

final shouldOverwrite = localStreak.isEmpty ||
    (supabaseUpdatedAt != null &&
        (localLastSyncAt == null ||
            DateTime.parse(supabaseUpdatedAt).isAfter(DateTime.parse(localLastSyncAt))));

if (shouldOverwrite) {
  // Overwrite local with Supabase
```

**Rule:** `shouldOverwrite` = local empty OR (Supabase has updated_at AND (local has no last_sync_at OR Supabase.updated_at > local.last_sync_at)).

**Edge:** If Supabase has no `updated_at`, treat as "don't overwrite" (keep local) unless local is empty.

### Step 2.3: Update the "cache exists" Branch

**Current (lines 978-1013):** When local exists and last_sync_at != null, it only updates today_* if local today_date is null. It does NOT compare timestamps.

**New:** Same branch runs when `!shouldOverwrite`. In that case, we keep local. The existing logic that updates today_* when `localTodayDate == null && supabaseTodayDate != null` is a safe, narrow fix — keep it. But do NOT overwrite full streak data; we already decided to keep local.

**Result:** When `shouldOverwrite == false`, we skip the full overwrite. The existing "update today_* only" block is fine as a targeted sync for that edge case.

**File:** `lib/services/data_fetch_service.dart`

**Current (lines 536-562):** When Supabase returns data, it always overwrites local with `ConflictAlgorithm.replace`.

**2-4** plans `fetchAndMergeStreaks` with timestamp comparison. If 2-6 is done before 2-4, we should add timestamp check to `fetchStreaks` before overwriting:

// Before insert, read local

final localLastSyncAt = local.isNotEmpty ? (local.first['last_sync_at'] as String?) : null;
