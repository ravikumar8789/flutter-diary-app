# Phase 4.10: Add Timestamp Comparison (Supabase.updated_at vs Local)

**Goal:** When fetching streak from Supabase, only overwrite local when `Supabase.updated_at > local.last_sync_at` (or local empty). Never overwrite local if local is newer — local changes may be in sync queue.

**Rule:** Local is source of truth. Supabase is sync target. Only pull from Supabase when Supabase has newer data.

**Prerequisites:** Phase 1.1, 1.2, 1.3, 2.4–2.6 (destructive last_sync_at=null removed). DataFetchService reads from SQLite.

---

## 1. Timestamp Comparison Rule

| Condition | Action |
|-----------|--------|
| Local empty | Store Supabase data |
| Supabase.updated_at > local.last_sync_at | Overwrite local with Supabase |
| Supabase.updated_at ≤ local.last_sync_at | Keep local, do NOT overwrite |
| Local has is_synced=0 | Keep local, do NOT overwrite (already handled) |
| Supabase has no updated_at | Treat as "don't overwrite" unless local empty |

## 3. Implementation Steps

### Step 3.1: DataFetchService.fetchStreaks — Add Timestamp Check

**File:** `lib/services/data_fetch_service.dart`

**3.1.1** Current flow (lines 535-562): When `response != null`, immediately overwrites local.

**3.1.2** New flow: Before overwriting, compare timestamps.

```dart
if (response != null) {
  // Read local for timestamp comparison (we may have it from earlier in fetcher)
  final localForCompare = await db.query('streaks', where: 'user_id = ?', whereArgs: [userId], limit: 1);
  final localLastSyncAt = localForCompare.isNotEmpty
      ? (localForCompare.first['last_sync_at'] as String?)
      : null;
  final supabaseUpdatedAt = response['updated_at'] as String?;

  final shouldStore = localForCompare.isEmpty ||
      (supabaseUpdatedAt != null &&
          (localLastSyncAt == null ||
              DateTime.parse(supabaseUpdatedAt).isAfter(DateTime.parse(localLastSyncAt))));

  if (shouldStore) {
    await db.insert('streaks', {
      'user_id': response['user_id'],
      // ... rest of fields
      'is_synced': 1,
      'last_sync_at': DateTime.now().toIso8601String(),
    }, conflictAlgorithm: ConflictAlgorithm.replace);
  }
  // If !shouldStore: keep local, return local data for consumer (or return response — caller may expect Supabase shape)
  return response;  // Or return local if we kept it — caller expects streak data
}
```

**3.1.3** Return value: When we keep local, return local streak data (so caller gets consistent data). When we store, return response. Map local to same shape as Supabase response for consistency.

```dart
if (shouldStore) {
  await db.insert(...);
  return _mapLocalStreakToResponse(response);  // or return response
} else {
  // Return local data in same shape as Supabase response
  return localForCompare.isNotEmpty ? _mapLocalRowToResponse(localForCompare.first) : response;
}
```

**3.1.4** Simpler: Always return `response` when we have it (Supabase shape). When we don't store, we still return response for the "fetch" — but the local DB is unchanged. The caller might use this for display. The key is: we don't overwrite local when Supabase is not newer.

### Step 3.2: Handle Supabase updated_at Format

**3.2.1** Supabase returns `updated_at` as ISO8601 string (e.g. `2026-01-25T21:37:22.342228Z`). Local `last_sync_at` is ISO8601. Use `DateTime.parse()` for both.

**3.2.2** Edge: If parse fails, treat as "don't overwrite" (safe).

```dart
bool _isSupabaseNewer(String? supabaseUpdatedAt, String? localLastSyncAt) {
  if (supabaseUpdatedAt == null) return false;
  if (localLastSyncAt == null) return true;
  try {
    return DateTime.parse(supabaseUpdatedAt).isAfter(DateTime.parse(localLastSyncAt));
  } catch (_) {
    return false;
  }
}
```

## 4. Edge Cases

| Case | Handling |
|------|----------|
| Local empty, Supabase has data | Store (shouldStore = true) |
| Local empty, Supabase null | Create default record (current behavior) |
| Local has data, Supabase newer | Overwrite |
| Local has data, Supabase newer, local is_synced=0 | Already handled: fetchStreaks returns local early when is_synced=0, never reaches Supabase overwrite. So we're good. |
| Local has data, Supabase newer, local is_synced=1 | Overwrite (correct) |
| Local has data, Supabase same or older | Keep local |
| Supabase.updated_at parse error | Don't overwrite |
| local.last_sync_at parse error | Don't overwrite (treat as "local has sync time") |
