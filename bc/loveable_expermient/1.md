# **DIARY JOURNALING APP - UI DESIGN PROMPT FOR LOVABLE AI**

## **📱 APP OVERVIEW**

Build a beautiful, modern mobile journaling app UI (Flutter/Dart) with comprehensive wellness tracking, AI-powered insights, and personal growth features. The app helps users maintain daily journaling habits, track mood and wellness metrics, receive AI-generated insights, and analyze their emotional patterns over time.

**Target Platform:** Mobile (iOS & Android)  
**Framework:** Flutter  
**Design Approach:** Modern, clean, user-friendly, with emphasis on emotional well-being and personal growth

---

## **🎯 CORE FEATURES & FUNCTIONALITY**

### **1. AUTHENTICATION & ONBOARDING**
- **Login Screen:** Email/password authentication
- **Register Screen:** User registration with email verification
- **Splash Screen:** App initialization and loading
- **Privacy Lock Screen:** PIN-based app lock (4-6 digits)
- **PIN Setup Screen:** Initial PIN creation
- **PIN Recovery Screen:** Recover PIN using security questions
- **Change PIN Screen:** Update existing PIN
- **Security Questions Screen:** Set up recovery questions

### **2. HOME SCREEN (Main Dashboard)**
**Key Components:**
- Welcome message with user's display name
- **Streak Counter:** Current and longest journaling streak with visual indicator
- **Today's Entry Status:** Quick access to create/edit today's entry
- **AI Insight Card:** Display yesterday's or today's AI-generated insight
  - Shows sentiment (positive/neutral/negative)
  - Insight text summary
  - Topics extracted from entries
  - "View Full Insight" button
- **Quick Stats Cards:**
  - Mood average (1-5 scale)
  - Water intake (cups per day)
  - Self-care completion rate
  - Consistency score
- **Quick Actions:**
  - Write New Entry
  - View History
  - Check Analytics
- **Grace Pieces System:** Visual indicator of grace pieces earned (for streak maintenance)

### **3. DAILY ENTRY CREATION/EDITING**
**New Diary Screen Features:**
- **Date Selection:** Calendar picker (allows backdating)
- **Mood Score:** 1-5 scale selector (visual emoji/color indicators)
- **Diary Text:** Rich text editor with auto-save
- **Tags:** Add custom tags to entries
- **Morning Rituals Section:**
  - Affirmations (dynamic list, add/remove items)
  - Priorities (dynamic list, add/remove items)
- **Wellness Tracker Section:**
  - Self-care checklist (10 items):
    - Sleep
    - Get up early
    - Fresh air
    - Learn something new
    - Balanced diet
    - Podcast
    - Me moment
    - Hydrated
    - Read book
    - Exercise
  - Meal tracking:
    - Breakfast (text)
    - Lunch (text)
    - Dinner (text)
    - Water cups (0-8 selector)
  - Shower/Bath tracking:
    - Took shower (yes/no)
    - Note (optional text)
- **Gratitude Section:**
  - Dynamic list of grateful items (add/remove)
- **Tomorrow Notes Section:**
  - Dynamic list of notes for tomorrow (add/remove)
- **Save/Cancel buttons**
- **Auto-save functionality** (debounced)

### **4. HISTORY SCREEN**

### **5. ANALYTICS SCREEN**
**Three Period Views: Weekly, Monthly, Period Comparison**

#### **5.1 Weekly Analytics View:**
- **Summary Cards:**

  - Average water cups
  - Self-care completion rate (%)
  - Consistency score (0-100%)
  - Total entries count
  - Total words written
- **Daily Progress Bar Chart:**
  - 7 bars (one per day: Mon-Sun)
  - Each bar shows 3 metrics:
    - Mood (green, 1-5 scale)
    - Water cups (blue, 0-8 scale)
    - Self-care completion (purple, 0-1 scale)
  - Interactive: Tap bar to see day details
  - Day labels below each bar
- **AI Weekly Insights Card:**
  - Week range (e.g., "Dec 14 - Dec 20")
  - Highlights (summary paragraph)
  - Key Insights (4-5 bullet points)
  - Recommendations (2-3 actionable items)
  - Mood Trend badge (improving/declining/stable/volatile)
  - Habit Correlations:
    - Mood vs entries correlation
    - Self-care completion impact
    - Mood vs gratitude correlation
    - Mood vs affirmations correlation
    - Sentiment distribution (positive/neutral/negative counts)
    - Consistency impact (high/medium/low)
- **Top Topics:** List of most mentioned topics
- **Yesterday's Insight Status:** Card showing if yesterday's insight is ready
- **Period Comparison Card:** Compare current week vs previous week
- **Daily Insights Timeline:** Chronological list of daily AI insights for the week

#### **5.2 Monthly Analytics View:**
- **Summary Cards:**
  - Average mood
  - Total entries
  - Average water cups
  - Average self-care rate
  - Overall consistency
- **Weekly Mood Chart:** Line/bar chart showing mood trends across weeks in month
- **AI Monthly Insights:**
  - Monthly highlights
  - Growth areas (list)
  - Achievements (list)
  - Next month goals (list)
  - Monthly mood trend
  - Habit analysis (JSON data)
- **Top Topics:** Most mentioned topics for the month
- **Combined Topics:** Aggregated topics across all entries

#### **5.3 Period Comparison View:**
- Compare current period vs previous period
- Metrics shown:
  - Mood change (with arrow indicator)
  - Entries count change
  - Consistency change
  - Self-care rate change
- Visual indicators (up/down arrows, color coding)

   - Splash → Register → PIN Setup → Home

2. **Returning User:**
   - Splash → PIN Lock (if enabled) → Home

3. **Create Entry:**
   - Home → New Diary → Fill all sections → Save → Home

4. **View History:**
   - Home → History → Select entry → View details

5. **Check Analytics:**
   - Home → Analytics → Switch between Weekly/Monthly views

6. **View AI Insights:**
   - Home → Yesterday Insight Card → Full insight screen
   - Analytics → Daily Insights Timeline → Individual insight

7. **Track Wellness:**
   - Home → Wellness Tracker → Fill checklist → Save

8. **Morning Rituals:**
   - Home → Morning Rituals → Add affirmations/priorities → Save
