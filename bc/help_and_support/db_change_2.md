## **📝 FIELD DESCRIPTIONS**

### **closure_note**
- **Type:** text (nullable)
- **Purpose:** Admin can add notes when closing ticket
- **Usage:** Visible to user in "My Tickets" when ticket is closed
- **Example:** "Issue resolved in v1.1.0. Please update the app."

### **email**
- **Type:** text (nullable)
- **Purpose:** User email for support team contact
- **Usage:** Auto-populated from user data on ticket creation
- **Source:** `users.email` or `auth.users.email`

### **app_version**
- **Type:** text (nullable)
- **Purpose:** Track app version for version-specific issues
- **Usage:** Auto-populated from package info on ticket creation
- **Format:** "1.0.0" or "1.0.0+1" (version+build)

### **device_info**
- **Type:** jsonb (nullable)
- **Purpose:** Store device/platform information for debugging
- **Usage:** Auto-populated from device info on ticket creation
- **Structure:**
  ```json
  {
    "platform": "android" | "ios",
    "version": "15.1.2",
    "is_debug": false,
    "device_model": "Samsung Galaxy S21" (optional)
  }
  ```

**Solution:** Ensure JSONB data is valid JSON:
```sql
-- Valid JSONB example

```

### **Issue: Cannot insert into jsonb column**
**Error:** Invalid input syntax for type jsonb

**Solution:** Use proper JSONB casting:
```sql
-- Correct
device_info = '{"key": "value"}'::jsonb

-- Incorrect
device_info = '{"key": "value"}'  -- Missing ::jsonb
```
